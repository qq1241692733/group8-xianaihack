# 15 · 首页界面方案

**这一篇是首页的现行方案**：结构、那颗球、攒元素的手势、三个方向、动效纪律、
昼夜差异，以及它在 `app/` 里落在哪些文件。**只写现在是什么，不写怎么演进来的。**

## 一 一句话

首页立的是「此刻正在发生」，不是一个仪表盘。

一屏只有**一颗球、三个入口、一个长按**。没有专注时长、没有完成率、没有连续天数、
没有「今天你拥有 2 小时 47 分钟」这类不评价但仍是数字语言的说法 —— 首页不出现任何数字。

**昼 / 夜是同一套结构、同一套信息设计，只差色板。** 两版共享同一颗蓝球，
差别只在「光往哪走」（见 §八）。

## 二 屏幕结构

自上而下，位置是固定的：

| 元素 | 位置（本页容器为 370 宽） | 说明 |
| --- | --- | --- |
| 身份栏 | 左上，`top:6px` | 衬线「此刻」+ 一行 `09.26 星期六`。**压顶、不与球心对齐** |
| 设置 | 右上，同在身份栏那一行 | 一枚安静的滑杆图标（两横杠，上面那颗滑钮在左、下面那颗在右）。见 §七 |
| 球 + 攒下的元素 | 球心距顶 `290px`，画布 280×280（外框 300×300） | 整屏唯一的主体、唯一的颜色 |
| 三个入口 | 底部控制簇的第一行 | 文字 / 图片 / 声音。点一下往球上攒一个 |
| 交互提示 | 控制簇里，入口之下 | 随攒了几件而变，见 §五 |
| 长按「记下此刻」 | 控制簇的最后一行，左右各 26px，高 52px | 唯一的实心胶囊；长按才落下 |
| TabBar | 距底 `18px` | 悬浮胶囊，四个 Tab |

**底部控制簇**（`.controls`）把三个入口、提示、长按按钮收在**同一个锚底容器**里
（`bottom: 96px`，纵向排列、间距 15px，停 TabBar 上方 26px）。为什么：三段各自钉 `top`
时，入口会浮到屏幕中间、拇指要往上够，而且它们与长按按钮的距离随内容高度变。收成一簇、
锚底之后，「入口 → 长按」的间距是常量，永远在拇指半径内 —— 这是这一屏唯一的操作动线。

> 基准稿 `index_demo_light_v2.html` 是 375 × 812（含它自己那条 44px 状态栏），
> 本页状态栏 56px 且在容器之外 —— 两边可用高度一致；纵向数字按本页重排过。

## 三 那颗球

球是**一层网点**画出来的：一层网点预渲染到离屏画布，每帧只做合成 + 高光 + 描边。
**密度就是那个数字** —— 留下得越多，网眼越密。界面上不写条数，密度替它说完。

- 0 级的直径 190、网点间距 3.10；每密一级，直径 `+2.1`、间距 `-0.052`，暗部再往深处走一档。
- 密度级 = `min(9, floor(sqrt(记录数) * 1.7))`，**再加上攒着、还没落下的件数**（最多 +3）。
  开方是为了压住前期：第一条带来的变化最明显，第 20 条几乎看不出来。
- 呼吸 = 网点的整体聚散，**不是形状变形**（形状抖动在浅底上会脏）。
- 受光点在左上（`0.30 / 0.24`），全 App 只有这一个光源方向。
- 纹理是**确定性**的（`mulberry32(20260926)`）：同一颗球每次画出来必须一模一样。
  会抖的纹理不是材质，是噪音。
- **夜版的辉光必须在画布内衰减到 0**。画布是方的：按球径的 2 倍去铺，圆的边会超出画布，
  于是整块画布被铺上一层淡蓝、**边是直的** —— 夜里能看见一个方块（踩过）。
  半径上限因此收在 `min(CW,CH)/2 - 12`（再扣 12px 给方向偏移留量），按下时的外光晕同理。

理解页落地页那枚 34px 的小显影是**同一颗球**（同一套几何，只是直径不同）——全 App 只有一颗球。

## 四 底部控制簇：唯一的操作动线

屏幕中段不再有内容（原来那句「生活证据」已删——它的位置不该换一种数字去填）。
于是**三个入口、提示、长按按钮统一收进底部一簇**（`.controls`，锚底 `bottom: 96px`），
拇指够得到的地方只有这一簇。

- **为什么不是三段各自钉 `top`**：那样入口会浮到屏幕中间、拇指要往上够；而且它们与长按
  按钮的距离会随提示语变。收成一簇、锚底之后，「入口 → 长按」的间距是**常量**，
  永远落在拇指半径内。
- **位置**（本页高 767，TabBar 占 697–750）：入口行约 483–529，提示 554–569，
  长按胶囊 594–646；三行间距 15px，整簇停在 TabBar 上方 26px。
- **球的让位**：球仍悬在上半屏（球心距顶 290px），卫星卡最远落到约 326px，
  与底部的入口行（约 483px 起）之间留着一整段空 —— 攒下的卡永远不会压到拇指区。

## 五 攒元素，然后长按落下

一次记录不是一个动作，是**攒**：点文字 / 图片 / 声音往球上攒一个元素（落成绕球的小卡），
攒够之后**长按「记下此刻」900ms**，攒下的全部一次落下、共享一个 `momentId`。
它们从此是**一件事**，不是一张照片加一句话。

| 环节 | 行为 |
| --- | --- |
| 点入口 | 开对应的采集浮层（写下 / 看见 / 听见），采完**不落库，只攒起来** |
| 攒下 | 元素变成一张小卡落在对应方向，入口上的计数徽章亮起，球跟着密一点 |
| 取下 | 点小卡上的 ×，把它拿下来 |
| 长按 | 进度在胶囊里走；满 900ms 才落下 |
| 松手太早 | 取消，回到原状（进度条收回） |
| 落下 | 小卡飞回球心 → 球变密 → 一圈极淡涟漪。**落库已完成，这只是一次让眼睛看完的动作** |

**提示语随状态走**（同一位置的第三行小字）：

| 攒了几件 | 提示 |
| --- | --- |
| 0 | 这一刻，你想留下什么？ |
| 1 | 还想加点什么？ |
| ≥2 | **长按下面的按钮，记下此刻**（转暖色） |
| 刚落下 | 刚记下一件。再攒一件？ |

**为什么是长按而不是点一下**：点一下太容易误触，而「落下」是一次确定的、成组提交的动作。
长按的判定有三条独立的路（rAF / 定时器 / 松手时的墙钟）——切走的标签页会同时节流
rAF 与 timer，只有墙钟还说得出「其实按够了」。三条都在 `holdController.ts`。

## 六 三个方向 → 三种「留下」

| 方向 | 入口 | 落点 | 留下什么 |
| --- | --- | --- | --- |
| 上 | 文字 | 居中衬线输入区 | 一句话（≤60 字）。交出去时那句自己淡掉、虚掉 |
| 左 | 图片 | 取景框（四角括号 + 对焦） | 一张照片。快门的面就是那颗球（70px）。**不用对准 · 不求清楚** |
| 右 | 声音 | 一圈声音的圆（250px） | 一段环境声。圆环由**真实麦克风电平**驱动，**不显示秒数** |

三条路的共同点：

- 浮层里**没有再问一遍的中转页**：要留什么，你点的那个入口已经说了。
- 采完**没有汇总页、没有 toast、没有对勾**。浮层直接收起，由首页接住：小卡落到球边，
  等长按才一起落下。
- 相册一次连选多张是**一个例外**：它本身就是一件事，所以整组直接落成一个「此刻」，
  不必再长按一次（`PhotoCapture` 的 `takeFiles`）。
- 拿不到摄像头 / 麦克风时**如实降级**，不假装有信号。

## 七 右上角那枚图标：设置

一屏只留一个发光体，所以右上角只放一枚**安静的滑杆图标**：不上色、无底、无环，
触摸目标靠 padding 撑起来。它不产生记录、不改时间流 —— 改的只是这一屏怎么发光。

点开是**设置**浮层（`SettingsOverlay`），眼下只有一件事：**外观**。

- 三个状态：**跟随系统**（默认）/ 白天 / 黑夜。真机上「白天黑夜」本来是系统级设置，
  产品不必另立一套，手动选择只是覆盖它。
- 真值仍只有一处（`document.documentElement.dataset.theme`，见 [03](03-技术架构.md) §八），
  所以浮层里点一下，球的色板、令牌、画布一起换。
- 外壳上还留着同一组开关（`ThemeSwitch`），但那只是给路演与无头截图用的快捷方式，
  不再是产品里唯一的入口。

> **「什么也不留」去哪了**：它不再占首页右上角，但那一屏还在（`NothingOverlay`），
> 从「理解」的对话出口进得去。不留仍然是完整的 —— 只是它不必再和三个采集入口
> 抢同一块屏幕。

## 八 动效纪律

| 纪律 | 落点 |
| --- | --- |
| 不给奖励性反馈 | 落下之后没有 toast、没有对勾、没有撒花。球静默变密 + 一圈极淡涟漪（180px，0.95s） |
| 不做弹跳 | 按下与方向偏移走指数逼近（无过冲）；进食弹簧 `k=58, c=8.2`，理论上有回弹但幅度落在 1px 以内，读不出来。小卡入场用一条 0.42s 的回弹曲线，落回球心用缓出 |
| 逐帧不 setState | 球与长按进度都直接写画布 / DOM；React 只管状态切换 |
| 动效不承担信息 | 关掉全部动效后，每个状态依然完整可读 |

一屏只有一个强调色（金），它只留给两处：攒够之后那句提示、以及入口上的计数徽章。

### 昼夜：只差色板

同一套结构，两套值。真值是 `html[data-theme]`，组件一律读令牌。

| | 昼 | 夜 |
| --- | --- | --- |
| 屏幕底 | `#FDFDFC`（哑光纸白） | `#090D13`（墨蓝黑，不是纯黑） |
| 球亮部 / 暗部 | `#B7CFFA` / `#3A5ED6` | `#A9C8FF` / `#1C3488` |
| 球是什么 | **墨点** —— 留下越多越**沉** | **光源** —— 留下越多越**亮** |
| 常驻辉光 | 无（纸白上辉光只会糊出一圈脏） | 有，半径克制在 `2R` 以内 |
| 主操作底 | `#111112`（黑胶囊） | `#E8EEF7`（月白）+ 深字 |

要点：**`--black` 会翻转**（它指「主操作底」，不是「黑色」）；**球的暗部必须比屏底亮**，
否则球不是球，是一个洞。

## 九 无障碍与降级

- 三个入口、长按胶囊、右上角「设置」都是真正的 `<button>`：键盘可达、焦点可见。
  「设置」那枚没有文字，所以它的名字放在 `aria-label` 里。
- 长按胶囊上 `Enter` / `空格` **按住**即开始计时、松开即判定（键盘也有「按住」）。
  `Esc` 取消。
- 读屏：攒了几件、落下的那一刻各播报一次（`aria-live`）。
- `prefers-reduced-motion`：呼吸 / 涟漪 / 碎片收敛，小卡不做入场回弹，直接落位。
- `prefers-contrast: more`：小字提到 `--ink`。

## 十 落在 `app/` 哪里

| 文件 | 管什么 |
| --- | --- |
| `src/screens/MomentScreen.tsx` | 屏幕骨架：身份栏 / 球 / 底部控制簇（三个入口 / 提示 / 长按胶囊） |
| `src/features/timefield/dotOrb.ts` | 网点球：`drawDotOrbTexture`（铺网，静态头像与首页同源）+ `DotOrb`（呼吸 / 按下 / 进食 / 变密）+ `ORB_THEME` |
| `src/features/timefield/useMomentStage.ts` | rAF 主循环 + 建球 + 密度 + 收下一条的碎片 |
| `src/features/timefield/holdController.ts` | 长按 900ms 的判定（rAF / 定时器 / 墙钟三条路，**纯逻辑，可测**） |
| `src/features/timefield/SatelliteLayer.tsx` | 攒下的元素：绕球三个方向的小卡 |
| `src/features/timefield/evidence.ts` | 记录数 → 密度级（**纯函数**） |
| `src/features/timefield/sparks.ts` | 碎片飞回球心 |
| `src/features/timefield/home.module.css` | 本页样式 |
| `src/app/store.ts` | 攒元素的暂存区（`staged` / `stageDraft` / `commitStaged`） |
| `src/features/memory/repo.ts` | `addMoment`：一个 Dexie 事务写下共享 `momentId` 的整组 |
| `src/features/capture/*` · `src/features/nothing/*` | 三条「留下」的浮层 + 「什么也不留」 |
| `src/app/SettingsOverlay.tsx` | 设置浮层（外观：跟随系统 / 白天 / 黑夜） |

**数据层只加了一个字段**：`Entry.momentId`（可选）。标签维度、IndexedDB 版本、
discoveries 判据、对账测试锁的数字都没碰。密度与那句仍是纯派生。

## 十一 怎么验

```bash
cd app && npm run dev
```

| 开关 | 作用 |
| --- | --- |
| `?stage=field` | 跳过开场，直接看首页 |
| `?stage=staged` | 跳过开场，并在首页攒好三件（一句话 / 一段声音 / 一张照片） |
| `&theme=day` / `night` / `system` | 强制主题（截图核对用） |
| `&cap=1` | 关掉全部过渡与动画，把弹簧写成终态（无头截图用） |

端到端：点文字写一句 → 卡落在球上方；再拍一张、录一段 → 卡分落左右；
长按「记下此刻」→ 三张卡飞进球心 → 去「时间」页应见 3 条、
它们共享一个 `momentId`（DevTools 里查 IndexedDB 的 `cike` 库）。
**绑定检索**：让某判据只命中其中一条，去「发现」页确认那一册把同组另外两条一起带出来。

**基准稿是设计稿，不能当产品画面用** —— 要出片一律用 `app/` 真跑的截图。

## 十二 还没定的事

1. **默认主题**：`app/` 现在跟随系统（`prefers-color-scheme`），而文档层已经拍板「默认昼」。
   是否把 `theme.ts` 的默认也压成昼，待一句话。
2. **球在夜版的「网点间隙露黑底」**：是保留的质感（像月光透过纱），还是希望更实一点。
3. **卫星卡的距离**：现在按 300px 球框定的值（文字 150 / 左右 112），
   在 370 宽的屏上还要一眼看着舒服 —— 待出真机截图后微调。
