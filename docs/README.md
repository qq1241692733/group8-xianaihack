## 一句话版本

「此刻」不是要解决什么问题，它只是**换一种记录方式**：用照片、声音和一句话，
留下一个场景（而不是一个文件）。首页只有一颗**会随着今天留下的东西变密**的球，不给数字。
留下之后，AI 按线索把散落的碎片串起来、原样呈现 ——
意义和感受由你自己认出来。
