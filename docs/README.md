## 一句话版本

「无用之用」是一款反效率的时间感知 App。它不逼你管理时间，而是允许你先停下来，
用声音、照片和文字留下此刻；AI 从这些被忽略的时间里帮助你重新看见自己。
当你真正因为意义而想行动时，原本按不下去的专注按钮，才会为你亮起。
