# 00 · 项目背景

> 本篇解决「为什么做」。技术内容一律以 [`app/`](../app/) 真实代码为准；
> 界面长什么样见 [15](15-首页界面方案.md) / [17](17-四屏界面方案.md)。

## 一句话定义

> 用一张照片、一段声音、一句话，留下一个场景。
> 那些看起来没用、后来自己也快想不起来的碎片，
> 会被线索串起来，把原本的意义和感受还给你。

产品名：**此刻**。

## 叙事总纲（2026-09-27 定，勿回退）

```
① 先说「无用」 → ② 再说为什么做它 → ③ 落在「换一种记录方式，能得到什么」
```

两条硬口径：

1. **不是想解决什么问题。** 本产品不写「痛点 → 解决方案」，不靠制造焦虑立论。
2. **不是替代谁，是换一种记录方式。** 相机、录音机、备忘录一直都在，
   「此刻」改的是**记录的单元**（从「一个文件」改成「一个场景」）与**事后能不能再被找回**。

> 早期的「反效率 / 时间被当成资源 / 自责循环」那套说法**已作废**，不要再用。
> 产品的立场不是反对效率，而是：**记录这件事，本身可以不为什么。**

## 一、先说「无用」

手机里存着很多这样的东西：

- 一段十几秒的录音，不知道当时为什么录；
- 一张照片，拍的是一棵树、一个楼道、一只猫，说不清它有什么意义；
- 一句话，写在备忘录角落里 ——「今天风很大」「终于没人找我了」。

它们不构成任何成果，不指向任何目标，甚至**过一段时间，连你自己都想不起来为什么会留下**。

> **无用 = 记录当时，你不知道它有什么用。**

**不要求它们后来变得有用，也不要求它们完整。**
可以只是一段声音，或只是一句话，或只是一张照片。

> **记录一个场景，不是完成一张表。**

### 但「无用」不是「没有价值」

> **无用之用 —— 不是没有价值，而是价值要在关系里才显现。**
> 一张照片没什么；当它和那段风声、那句话、三个月后的另一张照片放在一起时，
> 原本的意义和感受才回来。

## 二、为什么做它：整理旧文件时，线索自己浮了出来

起点不是「我发现了一个痛点」，而是一次很普通的整理。

把过去攒下的照片、录音和备忘重新翻了一遍 —— 本来只是想归置文件，
结果翻着翻着，一些东西自己浮了出来：

- 不同日期拍的那棵树下，好几张照片里都有一只白猫 —— 拍的时候根本没看见它；
- 一段风声，和那句「这道纹路，像老家院子里的那棵树」，是同一个下午留下的；
- 某一个时刻，在后来其实重复出现过很多次，只是每次都散在不同的地方。

**这些关系一直都在，只是散落着，没有人把它们摆到一起。**
一旦摆到一起，意义和感受就自己回来了 —— 而我什么都没有添加，只是重新看了一遍。

于是有了这个判断：

> 如果**记录的时候就是按「场景」记的**，而不是按「文件类型」存的
> （照片进相册、录音进录音机、文字进备忘录），
> 那后来的这一次整理，就不用再从头重来一遍。

**「记录此刻」因此而生 —— 它不是为了解决什么问题，只是想换一种记录方式。**

## 三、换一种记录方式，能得到什么

| 换掉的东西 | 换成什么 | 得到什么 |
| --- | --- | --- |
| 一个文件一条记录 | **一个场景一条记录**（共享 `momentId`） | 照片、声音、文字合起来才是那个场景 |
| 必须凑齐三种素材 | **不必凑齐**，单一类型也成立 | 记录一个场景，不是完成一张表 |
| 事后按时间倒序翻文件 | **按线索串起来**（一个词 / 一样东西 / 一句话） | 回看时回到现场，而不是翻到文件 |
| AI 解释、总结、给结论 | **只呈现，不解释** | 意义由你自己认出来，不替你编 |

四条展开：

1. **一个场景，是一条记录，不是三个文件。** 三个入口攒在一起，长按一次一起落下。
2. **留下的是感受，不是文件。** 回看时照片出现、风声真的响起来、那句话还在。
3. **线索会把散落的碎片串起来。** 不看时间，所以跨月、跨年的碎片也能拢到一条线上；
   也可以主动开口：「把以前记下的那些第一次，也帮我找出来。」
4. **它只呈现，不解释。** 不给结论、不打分、不贴标签、不催行动；
   呈现出来的每一样东西，都必须来自用户自己留下的材料。

> **我负责留下当时在意的东西，AI 帮我看见它们之间的联系。**

## 四、核心路径

```
留下正在发生的生活  →  时间慢慢形成纹理  →  AI 把散落的碎片串起来
                    →  我决定接下来怎么办
```

**行动只是可能的结果之一，不是产品终局。**
这几个出口都同样成立：决定开始做某件事 / 决定放下它 / 发现自己其实很喜欢某件事 /
意识到某段时间总在重复 / 只是重新听到三个月前的一段雨声。

产品要想的从来不是「推着人往前走」，而是：
**当一个人愿意回头看的时候，那些碎片还在，而且还能被认出来。**

## 五、边界：不做什么

| 不做 | 因为 |
| --- | --- |
| 排行榜 / 连续打卡 / 完成率 | 会把注意力从「那一刻」挪到「这个数」上 |
| 要求每次凑齐三种素材 | 记录一个场景，不是完成一张表 |
| AI 给结论、贴标签、打分 | 一旦替用户编意义，「只是呈现」就崩了 |
| 主动推送、催促、「你已 N 天没记录」 | 留下不该有压力 |
| 复杂社交 / 复杂商业化 / 过度复杂的 Agent 多工具调用 | 与「记录本身可以不为什么」冲突 |

> 这些不是「以后再做」，而是**与产品立场冲突**。

## 七、产品金句（节选）

- 相册保存的是文件；我们想保存的是感受。
- 无用不是没有价值，而是价值要在关系里才显现。
- 记录一个场景，不是完成一张表。
- 下次遇到一个舍不得忘的时刻，你不必只拍张照片就走。
- 我负责留下当时在意的东西，AI 帮我看见它们之间的联系。
- 无条件地留下，有条件地理解。
