# 00 · 项目背景

## 一句话定义

> 一个不急着让你变得更有效率的 App：允许你停下来，留下此刻，重新感知时间；
> AI 帮你理解自己，直到真正想行动的时候，再陪你开始。

产品名方向：**无用之用 / USELESS / 此刻**。

## 产品不是「记录浪费时间 App」

「记录浪费时间」是黑客松中最容易被理解的表层创意，但**不是**最终产品定义。
真正的产品命题是：

> 在一个所有人都被要求「变得有用」的时代，给人一个暂时不必有用的空间。

## 时代背景：绩效主义的时间观

现代效率工具几乎都在回答同一个问题：如何规划时间、如何提高专注、如何完成目标、
如何形成习惯。Todo、番茄钟、日程表、打卡、连续天数、完成率——本质上都在把时间
转换成**可管理、可衡量、可优化**的资源。

当「完成任务」意味着有用，那么没有完成任务的时间，就很容易被定义成无用。

## 真正的痛点：不是「不够自律」

- 为了一个宏大目标开始行动，却越来越痛苦。
- 把休息、发呆、娱乐都解释成「浪费」。
- 因为没有完成计划而产生自责，又用更强的计划惩罚自己。
- 越焦虑越想控制时间，越控制越无法自然行动。
- 很多人不是不知道应该做什么，而是**不知道自己为什么要做**。

## 产品判断

真正持久的行动，应该来自意义、兴趣、使命和内在动力，而不是持续的外部绩效压力。
因此改变不是从「逼自己做」开始，而可能从「允许自己停下来」开始。
**接纳不是放弃改变，而是改变真正能够发生的起点。**

## 为什么从「无用」开始

两条路径的对照，是理解整个产品的钥匙：

```
传统效率产品：  我不想做 → 强迫自己做 → 计时 → 完成 → 获得成就
无用之用：      我不想做 → 好，那就先不做 → 留下这一刻 → 感知自己
                        → 理解自己 → 真正想做 → 开始
```

需要澄清的是：**「无用」不是躺平**。产品不鼓励无休止逃避，也不把无用浪漫化，
它只是拒绝在用户还没有理解自己的时候，用绩效逻辑强行推动用户。

> 无为不是不行动，而是不强行作为，让真正的行动自然发生。

## 核心路径与终局

```
反效率 → 停下来 → 感知时间 → 留下此刻 → 理解自己 → 自主行动 → 再次感知
```

产品终局不是培养一个更自律、更高绩效的人，而是帮助一个人重新获得
**「我可以选择如何使用时间」**的能力。

## 「无用」与「有用」的边界

| 无用的表现 | 有用的表现 |
| --- | --- |
| 不可点击的效率按钮 | 重新感知当下 |
| 没有任务的界面 | 重新找回被遗忘的经验 |
| 没有完成率 | 理解自己的行为模式 |
| 允许发呆、允许不记录 | 发现真正想做的事 |
| 允许一段时间没有产出 | 开始一个足够小的行动 |
| 允许声音只是声音、照片只是照片 | 让行动回到自己的意义，而非外部绩效 |

> 「无用」不是目标，「有用」也不是目标。目标是让人重新拥有选择。

## 关键判断：为什么不用普通的时间管理 App 替代

因为普通时间管理解决的是「如何执行已经确定的目标」，而本产品首先处理的是更前面的
一个问题：**「这个目标真的是我想要的吗？」**

如果用户没有真正理解自己，再精细的计划都可能变成另一种压力。
因此产品故意保留「无用」阶段——

> 不是不让你行动，而是不替你决定为什么行动。

## 项目载体

本项目由三个产物组成，注意它们的分工：

| 产物 | 说明 | 状态 |
| --- | --- | --- |
| `产品&背景.docx` | 产品文档 V1.0，19 节，含体验、场景、金句、Demo 脚本 | 只读原件，本套文档的来源之一 |
| `index.html` | 单文件离线 Demo，已实现全部六层体验 | 视觉与交互参考稿，**不再维护** |
| `app/` | 正式前端工程（Vite + React + TS） | **本文档技术依据**，当前 M0–M1 |

`index.html` 之所以被重建为 `app/`：单文件形态状态散在闭包里、无类型、无测试、
无法插入 LLM 调用，接不了后续的记忆层与 AI 理解。重建同时修正了参考稿中已知的四个
问题（P0 叙事时序、XSS、文案错字、录音计时不进位）——详见
[04 · 技术实现](04-技术实现.md#六p0-叙事时序修正从第一天就按正确语义长状态机)。

## 产品金句（节选）

- 不是让每一分钟都有价值，而是让你重新感受到，时间是你的。
- 如果一段时间没有产生结果，它就真的毫无意义吗？
- 无用不是没有价值，而是价值尚未显现。
- 相册保存的是文件；我们想保存的是感受。
- 你不是缺少时间，你可能只是很久没有感受过时间。
- 无用是入口，感知是过程，理解是转折，行动是结果。
- 无用之用：先允许自己存在，行动才可能真正发生。
