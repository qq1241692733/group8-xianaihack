# 此刻 · 安卓安装与打包指南

> **APK 已经打好了，就在你桌面上，文件名叫「此刻.apk」。**
> 这篇文档分两部分：前三节讲怎么装到手机上，第五节讲以后想改内容怎么重新打包。

---

## 一、你手上现在有什么

| 东西 | 位置 | 说明 |
| --- | --- | --- |
| **此刻.apk** | 桌面 | 安装包本体，**4.1 MB** |
| 归档副本 | `D:\ai\the_time\release\此刻-debug.apk` | 备份，别删桌面那份 |
| 安卓工程 | `D:\ai\the_time\app\android\` | 随时可以重新打包 |

这个 APK 里装的是 `app/` 编译出来的网页，外面套了一层原生安卓壳（Capacitor）。
装到手机上后，桌面会多一个叫「**此刻**」的图标，点开是**全屏运行**的，没有浏览器地址栏。

**支持 Android 7.0 及以上**，现在在用的手机基本都满足。

## 二、装到手机上：三步

### 第 1 步 · 把 APK 传到手机

三种方式，挑最顺手的：

| 方式 | 具体操作 |
| --- | --- |
| **微信**（最省事） | 电脑微信打开「文件传输助手」→ 把桌面「此刻.apk」拖进去 → 手机微信打开同一个「文件传输助手」→ 点这个文件 → 选择「用其他应用打开」 |
| **数据线** | 手机插电脑 → 手机上选「传输文件 / MTP」模式 → 把 APK 复制到手机「下载」文件夹 → 在手机的「文件管理」里点它 |
| **QQ** | 电脑 QQ 发给「我的手机」，手机 QQ 里接收 |

### 第 2 步 · 允许安装（第一次装一定会被拦）

手机会弹一个拦截提示，大意是「**已阻止安装**」或「**无法安装未知来源的应用**」。

1. 点弹窗里的「**设置**」
2. 找到「**允许来自此来源的应用**」并打开开关
   （华为叫「外部来源应用下载」，小米叫「安装未知应用」，OPPO/vivo 叫「允许安装未知来源应用」）
3. 返回，**重新点一次那个 APK**

### 第 3 步 · 安装并打开

点「安装」→ 等几秒 → 点「打开」。桌面出现「此刻」图标，搞定。

## 三、首次打开会要权限，给不给都能用

| 权限 | 什么时候弹 | 拒绝了会怎样 |
| --- | --- | --- |
| **麦克风** | 用「听见」录音时 | 录音那一项显示错误，**其它功能照常** |
| **相机** | 用「看见」拍照时 | 回落到内置画面，**其它功能照常** |
| **网络** | 安装时就带上了，不弹窗 | — |

**三个权限全都不给，App 也能正常打开、正常浏览**——这是刻意设计的降级路径，不是 bug。

### 关于 AI 对话

打包后的 APK 里**没有后端服务器**，所以「理解」板块里走模型的输入会失败并**如实地回落到一句兜底话**（`app/src/data/script.ts` 的 `FALLBACK_LISTEN`，不假装答过了）；本地能答的那部分（找回已有册、按标签检索）照常工作。

> 你 `.env.local` 里那把 API Key **不会、也没有**进安装包。Key 只活在电脑上跑开发服务器时用的那个中间件里，客户端产物里一个字都没有。

## 四、常见问题

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 提示「应用未安装」 | 手机里已有同包名的旧版，签名对不上 | 先卸载旧的「此刻」，再装 |
| 提示「解析包时出现问题」 | 传输时文件损坏（微信偶发） | 用数据线重传；或对比下文件大小是不是 **4.1 MB** |
| 装完打开是白屏 | 系统 WebView 版本太旧 | 应用商店里更新「Android System WebView」 |
| 录音点了没反应 | 之前拒绝过麦克风权限 | 设置 → 应用 → 此刻 → 权限 → 手动打开麦克风 |
| 想卸载 | — | 长按图标 → 卸载，和普通 App 一样 |

## 五、以后改了内容，怎么重新打包

改完 `app/src/` 里的代码后，依次跑这三步（在 Git Bash 或 CMD 里都行）：

```bash
# 第 1 步：重新构建网页产物
cd D:/ai/the_time/app
"C:/Users/guope/.workbuddy/binaries/node/versions/22.22.2-3/npm.cmd" run build

# 第 2 步：把网页塞进安卓工程
"C:/Users/guope/.workbuddy/binaries/node/versions/22.22.2-3/node.exe" \
  node_modules/@capacitor/cli/bin/capacitor sync android

# 第 3 步：编译 APK
cd android
JAVA_HOME="D:\dev\jdk-21" ANDROID_HOME="D:\dev\android-sdk" \
  "D:/dev/tools/gradle-8.14.3/bin/gradle.bat" assembleDebug --no-daemon
```

产物固定生成在：

```
D:\ai\the_time\app\android\app\build\outputs\apk\debug\app-debug.apk
```

首次编译约 20 分钟（要下载依赖），之后增量编译只要几十秒。

> **没有 Android Studio 也能打包**——本文这套流程用的是命令行工具链，只依赖 JDK + Android SDK + Gradle 三样，都已装好。

### 为了让它在国内网络能跑通，动过三个地方

国内直连 `dl.google.com` 只有 **约 20 KB/s**，腾讯云镜像能到 **350 KB/s**，差 18 倍。所以：

| 文件 | 改了什么 | 为什么 |
| --- | --- | --- |
| `C:\Users\guope\.gradle\init.gradle` | **新建**，Maven 仓库走阿里云镜像 | 拉 AGP、androidx 依赖不再卡 |
| `android/gradle/wrapper/gradle-wrapper.properties` | Gradle 分发源换成腾讯镜像 | 原来指向 services.gradle.org |
| `android/local.properties` | **新建**，`sdk.dir` 指向 `D:\dev\android-sdk` | 让 Gradle 找到 SDK |

前两个是纯下载源替换，内容都是官方二进制；`init.gradle` 放在用户目录，**没有改动工程文件**，以后升级 Capacitor 不会冲突。

### 关于签名

现在这个是 **debug 签名**（Capacitor 默认），特点是：

- ✅ 可以自己装到任何手机上反复用
- ❌ 不能上架应用商店，也不能作为正式发布包分发

要正式签名得生成 keystore 再配 `signingConfigs`，那是另一步，等你需要上架/分发时再说。

### 改过的安卓配置

| 位置 | 改动 | 原因 |
| --- | --- | --- |
| `AndroidManifest.xml` | 加了 `RECORD_AUDIO` / `CAMERA` / `MODIFY_AUDIO_SETTINGS` | WebView 里的录音和拍照要先声明权限，网页的权限请求才会变成系统弹窗 |
| `AndroidManifest.xml` | 主界面锁 `portrait` 竖屏 | 这个产品是按手机竖屏设计的，横屏会破版 |
| `capacitor.config.ts` | 新建，`appId=cn.wanyueyuan.cike`、`appName=此刻`、`webDir=dist` | Capacitor 的主配置 |
