## 一 三个板块的分工

| 板块 | 一句话职责 | 它不做什么 |
| --- | --- | --- |
| **时间** | 「最近发生了什么」——你留下的每一个此刻，按天排开 | 不做统计、不排名、不报数 |
| **发现** | AI 把记录整理给你看：**先材料，后结论** | 不给结论、不下判断、不催你行动 |
| **理解** | 你带着问题找回线索：说出大概，它把相关的记录翻出来 | 不做成聊天机器人、不主动给行动 |

三屏与首页**同构**：`eyebrow`（11px / .26em / `--ink-3`）→ `paneTitle`（衬线，大标题）→
`paneSub`（13px / `--ink-3`）。改字号只改一处原子。

## 二 颜色与层级纪律（三屏共用）

1. **入口没有新颜色。** 三屏加起来只有一个金色落点：发现页被保留那张卡的「已保留」。
   一颗球：理解页落地页里那枚 34px 的小显影（与首页**同一颗球**，只是尺寸不同）。
2. **深底上的层级靠亮面，纸面上的层级靠落影。**
   夜版卡片 = `--glass` 底 + 1px `--line` 边（比屏底亮一点）；昼版屏底已贴近白，
   一张更白的卡读不出来，所以必须补一层极浅的落影（`--lift` / `--lift-strong`）。
3. **金是动作的回执，不是装饰。** 它的定义是「你按下的那一下」——
   首页攒够之后那句提示与入口上的计数徽章 / 已保留 / 交给发现。
   `--warm-bright` 在昼版**更深**（见 §六）。
4. **筛选选中态的金不算「一屏一处金」**，它是一个视图状态，不是一次留下的判断。

## 三 时间

![时间 · 夜版](shots/17-时间-夜版.jpg) ![时间 · 昼版](shots/18-时间-昼版.jpg)

- 副题只有一句：**「你留下的每一个此刻。」** 不说「它们不组成成绩」——
  反驳一个概念等于给它一次曝光，而「成绩」是这一屏最不该出现的词。
- 分组头只有**日期 + 一条横线**，没有「N 个此刻」。列表本身已经说完了，不需要再报一遍数。
- 分类保持 `全部 / 声音 / 照片 / 一句话` 四类不变；**图标换成与底部导航同一套的线性图标**
  （emoji 是不受控的彩色像素，一次带进红黄绿三种色相）。
- **类型只在顶行出现一次**：照片行给缩略图、不念「照片」；副行**只属于声音**
  （「环境声音 · 22 秒」是它的一部分，不是重复）。
- 种类行与波形**都不上色**（走 `--ink-3`）。颜色不承担分类。
- **一次落下的几条收成一条**（共享 `momentId`，见 [15](15-首页界面方案.md) §五）：
  它们是「一件事」，摊成三行就把那件事拆散。收起来只露一行 —— 时间 + `此刻` +
  里面有哪些种类图标 + 一句**标题**（优先用你自己写的那句，那是这件事里唯一由你命名的
  部分；没写就退回最新那条的主文案）。点开才看得到里面的几条，缩进挂在一条细线上。
  **不报条数**：种类图标已经说完了。
  > 一个「此刻」落在它**最后发生的那一天**，不劈成两天 —— 库里那张照片可能带 EXIF
  > 更早的拍摄时间，但这件事是此刻发生的。分组逻辑是纯函数
  > `features/memory/timeline.ts` 的 `buildTimeline`，有测试。

## 四 发现

![发现 · 夜版](shots/17-发现-夜版.jpg) ![发现 · 昼版](shots/18-发现-昼版.jpg)

- **册架 → 卷内**（v5 起，见 [23](23-发现档案与守望.md)）：这一屏不再是「一条竖轴挂节点」——
  **册架**稀排大封面（一屏约一册半），点开进**卷内**，卷内按类型成段（声音 → 照片 → 一句话，
  从证据到人）；单类型册不显示段头。与时间页的分界不再是皮，是**节奏**：时间页密、小、匀；
  册架疏、大、不匀。
- **封面材质 = 主导类型**：声音册给一道固定几何的**波形地平线**，照片册给一条**胶片条**，
  一句话册给最大字号的原话。几何是固定的 —— 每次渲染都变形的波形不是证据，是噪音。
- **封面右上角一枚来源徽章**：守望册「留意着」、判据册「示例连接」、自建合集「自己拢的」。只出现一次。
- **「正在帮你留意」条**（`watchStrip`）：守望在发现页的常驻显影，点开就是它的**设定与管理**
  （设定是偶尔做的事，不该占着一屏 —— 入口因此从理解页搬到了这里）。
- 「示例空间 ↗」→ **「示例数据」**：带箭头的按钮在移动端是一个承诺（点下去会离开这里），
  而这里没有可去的地方 —— 箭头是假的。
- **新的记录放在最上边**：册按**册内最近一条**的时间倒序（`to` 就是那一册的
  `max(createdAt)`，是真实时间，不是「谁先被写进代码」）。一个刚刚还发生过的故事，
  比一个早已停下的故事更该先被看见。
  > 打平时 `Array.sort` 是稳定的，于是「守望册在前」仍然生效 —— 它没有被推翻，
  > 只是让位给刚发生过的事。落点是 `buildDiscoveries`，有对账测试盯着这个顺序。

## 五 理解

![理解 · 夜版](shots/17-理解-夜版.jpg) ![理解 · 昼版](shots/18-理解-昼版.jpg)

理解是**找回线索的落地页**，不是一场脚本对话。

- **空态**（还没说话时）是一句招呼「想找回什么？」+ 落地页里那枚 34px 的球（与首页**同一颗球**，
  同一套网点几何，只是尺寸不同）+ 「不必记得是哪一天。/ 说说你还记得的一点。」+ 三条示例。
  点一条示例就等于把这句话说出去 —— 走的是**同一条本地查询**。
- **界限靠形态，不靠颜色**：你说的**有气泡**（`--glass` 底 + 1px `--line` 边，不拉整宽）——
  那是一次动作；它回你的**没有气泡** —— 那是环境的一部分。
- **它回的是一段对话**：可以是几句判断、一份**册回执**（材质缩影 + 册名 + 期间，动作是
  「留下 / 不要」或「翻开来 →」），也可以是一组册行（点一行原地展开）。
  **阅读在发现页，这里只给回执**（docs/23 §三）。
- **底部输入区**：一行范围说明「本地查找 · 文字、标签与已识别内容」，一个**轮播灰字占位符**
  （「我想找⋯」「不必记得是哪一天。」…），右侧一枚发送圆钮。
- **页头右上角两枚按钮**：**历史对话**（打开归档列表）与 **新增对话**（把当前这段收进历史、
  开新的一段）。
- 它**不上金**：按「三屏只有一个金色落点」的纪律，它没有强调色。

## 六 昼夜：三件方向相反的事

**昼版不是夜版的反色。** 照抄任何一版都会坏：

| | 昼版（纸白底） | 夜版（墨蓝黑底） |
| --- | --- | --- |
| 球是什么 | **墨点** —— 留下越多越**沉** | **光源** —— 留下越多越**亮** |
| 球的两端 | `#B7CFFA` / `#3A5ED6` | `#A9C8FF` / `#1C3488` |
| 头像那枚 34px 的光 | 落影 `0 2px 10px -4px` | 发光 `0 0 24px -4px` |
| 层级怎么来 | 一层极浅落影（纸面上「更亮的底」无效） | 一个更亮的底 + 一条细边（深底上阴影无效） |
| `--glass` | `#FFFFFF`（比纸白更白的卡） | `rgba(238,241,246,.045)`（比屏底更亮的一层） |
| `--fill-2`（你说的话） | 压深一档 `#F1F1F3` | 提亮一档 `rgba(238,241,246,.10)` |
| `--warm` | `#B8842F` | `#E0A95E` |
| `--warm-bright` | **`#8A5F1C`（更深）** | `#F4D3A0`（更亮） |

`--warm-bright` 是**最容易静默出错**的一处：名字沿用夜版，但昼版要更深 ——
照抄夜版的 `#F4D3A0` 放到纸白上会淡到几乎看不见。

其余「深底上的亮线」在昼版统一落成「纸面上的暗线」：声波条
`rgba(238,241,246,.40)` → `rgba(16,16,18,.30)`，封面材质的线 `.30` → `.22`，依此类推。

**照片的降级画面**（拿不到相机时 `scene.ts` 画的那张「窗外」）：
夜版三层是暖光斑 + 深底，是对的；纸白上深底会读成一个「没加载出来」的深棕方块。
所以只把**底抬亮**（`linear-gradient(160deg,#D8DEE8,#E5DCCF 60%,#BFC5CE)`），光斑一个没动。

## 七 落在 `app/` 哪里

| 板块 | 主要文件 |
| --- | --- |
| 时间 | `src/screens/TimeScreen.tsx` + `.module.css`；线性图标在 `src/app/icons.tsx`（`KindIcon`） |
| 发现 | `src/screens/DiscoverScreen.tsx` + `.module.css`；判据与卡片在 `src/data/discoveries.ts`；自建合集 `src/data/collections.ts` + `src/app/NewCollectionOverlay.tsx` |
| 理解 | `src/screens/UnderstandScreen.tsx` + `.module.css`；落地页那枚小球 `src/features/timefield/OrbMark.tsx`；会话归档 `src/features/agent/sessions.ts`（`cike:sessions`）+ `src/app/HistoryOverlay.tsx` |
| 共用 | `src/app/Pane.tsx`（屏壳）· `src/app/TabBar.*`（悬浮胶囊）· `src/styles/atoms.css`（排版与控件原子）· `src/styles/tokens.css`（令牌） |

**数据层只加不改**：`Entry` 类型、IndexedDB（v1 的 entries/blobs/meta、v2 的 watches）、
`discoveries.ts` 的判据表、`seed.ts` 的 13 条种子、对账测试锁住的数字，全部没碰；
这一轮新增的是 v3 的 `collections`（自建合集，见 [03](03-技术架构.md) §五）。

## 八 怎么验

```bash
cd app && npm run dev
```

| 开关 | 作用 |
| --- | --- |
| `?stage=time` / `discover` / `understand` | 跳过开场，直达某一屏 |
| `&theme=day` / `night` / `system` | 强制主题 |
| `&cap=1` | 关掉全部过渡与动画（无头截图用） |

设计稿对拍：`index.html#theme=day|night`（合并后的单文件双主题稿）。
