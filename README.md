# 此刻 · Demo 初稿

一个不评价你的时间的地方。这不是时间管理工具，是一个「时间感知器」。

## 怎么打开

直接双击 `index.html` 即可（单文件，无需安装任何东西）。

## 建议体验路径

1. 开场点「进入」。
2. 首页看起来是个效率仪表盘（专注 / 完成率 / 连续天数 / 今日任务），但**它算不出任何数字**。
3. 按几次最大的那个 **开始专注** 按钮。它不会启动，只会躲开你，并依次说「为什么这么着急？」→「它不会启动。今天不会。」→「好。那就先不做。」
4. 然后点页面上**最小的**那行字 **留下一刻** —— 这是唯一真正管用的入口，而它故意做得最不起眼。
5. 选择 🎙 声音 / 📷 照片 / ✍️ 一句话，或 **什么都不留下**（和另外三个同等显眼）。
6. 回到首页：你的记录只变成一条**虚线**，没有数字、没有统计。这就是全片的转折——你做了唯一能做的事，而它不产生结果。
7. 也可以点 **不想做** 进「什么都不做」：呼吸圆环不设倒计时、不会完成，环境声音慢慢浮现。想走随时可以走。
8. 打开底部 **理解**，AI 不会给你报告，而是回应你留下过的时刻，最后给出「开始 3 分钟」——这一次按钮按得下去，因为那是你自己想做的。

想体验另一条分支：在「理解」里选「我也不知道」，AI 会翻出 8 月 17 日的记忆卡片。

## 无用体现在哪里

核心判断：**无用不是「不能」，是「不算」。**

- **数据层**：首页的专注时长与完成率永远显示 `—`，连续天数写「你没有在坚持什么」。时间流没有总数、没有图表。3 分钟专注**不计数、不进时间流、不留痕**。
- **交互层**：最显眼的按钮按不动；真正能做的事做得最小。留下记录后**不给奖励**（没有 ✦、没有"已保存"），只回原处。
- **文案层**：零鼓励。没有"很棒 / 加油 / 坚持得不错"，也不自称工具、不给建议。

所以「记录」不是和无用并列的另一个功能——**记录就是无用的存档方式**：它保留效率 App 会删掉的（一段空调声、一句"今天风很大"），删掉效率 App 会保留的（时长、完成率、连续天数）。

## 与传统时间管理 App 的关键差异

| 传统做法 | 「此刻」的做法 |
| --- | --- |
| 首页展示「今天浪费了 2h47m」 | 「今天，你拥有 2 小时 47 分钟」——不评价 |
| 主按钮「开始专注」按下去就计时 | 同一个按钮，按下去**不启动**。它在拒绝你 |
| 要求用户主动记录浪费时间 | 用户只需留下此刻，无用由 AI 自己发现 |
| AI 输出效率报告 | AI 重构你的时间叙事，帮你重新看见自己 |
| 专注 = 完成任务的 KPI | 专注 = 内在状态自然发生后的行动 |
| 记录会变成图表和数据 | 记录只留下一条痕，不进入任何统计 |

## 功能分区

- **此刻**：伪装成效率仪表盘的首页。大数字全是 `—`，最大的按钮按不动，仅提供「想做 / 不想做」。
- **什么都不做**（全屏）：呼吸圆环**不设时长、不会完成** + 环境声音浮现。没有进度可达成，想走就走。
- **留下此刻**（全屏）：声音 / 照片 / 一句话，外加「什么都不留下」——四个选项同等显眼。
- **时间**：时间流按「声音 / 照片 / 一句话」筛选，每条都是触感而非数字。
- **理解**：AI 三段式回应（让你看见当下 → 重新看见过去 → 理解自己），最后才是行动。
- **开始 3 分钟**（全屏）：从「我必须完成」变成「这是我真正想做的」。**用完不留痕，不进时间流。**

## 说明

所有数据均为演示用的模拟数据，刷新即重置。声音为可视化模拟，不调用真实麦克风。

## 设计裁决规则

有争议时按这几条判断：

1. 有用的事不留痕迹，无用的事才被留下来。
2. 不给进步，只给存在。
3. 不做评价，只做回应。
4. 不可用本身就是表达。
5. 任何需要「完成」的东西都是 bug。
6. 不是不让你行动，而是不替你决定为什么行动。
