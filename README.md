# 此刻 · Demo 初稿

一个不评价你的时间的地方。这不是时间管理工具，是一个「时间感知器」。

## 怎么打开

直接双击 `index.html` 即可（单文件，无需安装任何东西）。

## 建议体验路径

1. 开场点「进入」。
2. 首页点 **不想做** —— 这是产品的真正入口，而不是「开始专注」。
3. 界面进入「什么都不做」：30 秒呼吸圆环，没有倒计时、没有任务、没有 KPI，只有环境声音在流。
4. 30 秒后出现「留下这一刻」，选择 🎙 声音 / 📷 照片 / ✍️ 一句话，或什么都不留下。
5. 留下后点「去『时间』看看」，它会落进时间流。
6. 打开底部 **理解**，AI 不会给你报告，而是回应你留下过的时刻，最后给出「开始 3 分钟」——这一次按钮按得下去，因为那是你自己想做的。

想体验另一条分支：在「理解」里选「我也不知道」，AI 会翻出 8 月 17 日的记忆卡片。

## 与传统时间管理 App 的关键差异

| 传统做法 | 「此刻」的做法 |
| --- | --- |
| 首页展示「今天浪费了 2h47m」 | 「今天，你拥有 2 小时 47 分钟」——不评价 |
| 主按钮是「开始专注」 | 主按钮是「不想做」 |
| 要求用户主动记录浪费时间 | 用户只需留下此刻，无用由 AI 自己发现 |
| AI 输出效率报告 | AI 重构你的时间叙事，帮你重新看见自己 |
| 专注 = 完成任务的 KPI | 专注 = 内在状态自然发生后的行动 |

## 功能分区

- **此刻**：时钟 + 「想做 / 不想做」。选了「想做」就放你走，不要求回来汇报。
- **什么都不做**（全屏）：30 秒呼吸圆环 + 环境声音波纹，交互本身就在实现「无用」。
- **留下此刻**（全屏）：声音 / 照片 / 一句话三个入口，允许什么都不留。
- **时间**：时间流按「声音 / 照片 / 一句话」筛选，每条都是触感而非数字。
- **理解**：AI 三段式回应（让你看见当下 → 重新看见过去 → 理解自己），最后才是行动。
- **开始 3 分钟**（全屏）：从「我必须完成」变成「这是我真正想做的」。
