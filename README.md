# 此刻 · the_time

> 一个让你停下来、留下此刻、重新感知时间的地方。
> AI 帮你理解自己，直到你真正想行动的时候，再陪你开始。

---

## 背景

现代生活里，时间越来越像一种可管理的资源：要规划、要衡量、要优化。
一旦「完成任务」意味着有用，没有完成任务的时间就很容易被定义成无用 ——
不是被别人，是被自己。

于是休息、发呆、娱乐都被解释成「浪费」，没有完成计划就自责，
又用更强的计划惩罚自己，越焦虑越想控制时间，越控制越无法自然行动。

很多人不是不知道应该做什么，而是不知道自己**为什么要做**。

**此刻**想做的事很简单：在被要求「变得有用」之外，给人一个暂时不必有用的空间。
不是躺平，而是拒绝在你还没理解自己的时候，用绩效逻辑强行推着你走。

```
留下正在发生的生活 → 时间慢慢形成纹理 → AI 帮我重新看到那些我没注意到的
                    → 我决定接下来怎么办
```

行动只是可能的结果之一，不是终局。开始工作、放弃一个项目、发现自己其实很喜欢
某件事、只是重新听到三个月前的一段雨声 —— 这些出口都同样成立。

## 功能

### 首页：一颗会随时间变密的球

打开 App 第一眼不是功能，而是**一颗用网点画出来的球**。
留下的东西越多，网眼越密 —— 密度就是那个数字，**界面上一个数字都不写**。
它不是柱状图，不是统计，也没有打卡和连续天数。

### 记录此刻：文字 / 图片 / 声音

三个**真实**入口（真麦克风、真相机）收在屏幕底部同一簇里，
拇指半径内即可完成。可以一次攒下好几个再一起落下 ——
它们从此是**一件事**（共享同一个 `momentId`），不是三条记录。

- 照片，留下「我看到了什么」
- 文字，留下「我当时在想什么」
- 声音，留下「这一刻真实是什么感觉」

采完不给奖励：没有特效、没有「已保存」的成就感设计，东西只是悄悄攒到球边，
落下时球变密一点。什么也不留，也收在右上角一个安静的角。

### 发现：AI 是一面镜子，不是教练

AI 不每天汇报。只有它真的发现某个关系时，才出现一张卡 ——
点开看到的不是结论，而是**证据**：

> 9 月 3 日，23:47 —— 你留下了一段洗衣机的声音。
> 9 月 11 日，00:18 —— 你写：「终于没人找我了。」
> 昨天，23:52 —— 你什么也没写，只录了 31 秒窗外。
>
> 「这三次，你都在所有人安静以后才留下东西。」
> 「这是一天里唯一真正属于你的时间吗？」

先材料，后结论。先观察不评价，先提问不说教，不制造新的绩效压力。

### 理解：找回线索

说出大概，它把相关的记录翻出来；有历史对话，也可以开一段新的。
检索走**精确日期 + 聚合 + 文本兜底**三路，而不是语义相似 ——
「你还记得 8 月 17 日吗」靠的是日期，「你已经提到它 7 次了」靠的是跨条目聚合。

## 隐私

- **原音原图默认不出设备**：只有文本与标签会离开设备，原始音频 / 图片存本地
  IndexedDB，不出手机。
- **API Key 永不出服务端**：LLM 调用经开发期代理转发，Key 只在 `.env.local`。
- **能本地做的分析优先本地做**：标签提取默认走本地规则词典 + 元数据，不联网；
  「让 AI 看一眼画面」是默认关闭的可选增强层。
- AI 不贴心理疾病、人格标签；观察一律表达为「我注意到……」，而非「你就是……」。
- 可随时删除单条记录或全部时间档案。

## 技术栈

Vite · React 19 · TypeScript 5.9 · Zustand · Dexie(IndexedDB) · Zod · Vitest ·
Capacitor（安卓打包）。

本地优先：记忆层与原始媒体都在设备内，LLM 只是可选的增强层。

## 怎么跑

```bash
cd app
npm install
npm run dev        # 本地开发
npm run dev:host   # 局域网访问，自动挂自签证书（手机调试录音 / 拍照必需）
npm test           # vitest
```

---

所有数据均为演示用的模拟数据，刷新即重置。
录音与拍照走真实的 `MediaRecorder` / `getUserMedia`；
拿不到摄像头 / 麦克风时如实降级，不假装有信号。
